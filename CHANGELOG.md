# Changelog

All notable changes to the **Park Conscious** platform will be documented in this file.

## [1.1.0] - 2026-05-13

### 🚀 Monorepo Architecture
- **Turborepo Integration:** Migrated the project to a high-performance monorepo using Turborepo.
- **Workspace Standardization:** Unified the codebase into three main workspaces:
    - `@parkconscious/api`: Centralized backend nexus.
    - `@parkconscious/events`: Public-facing event discovery platform.
    - `@parkconscious/admin`: Management and health monitoring dashboard.
- **Parallel Task Orchestration:** Enabled parallelized `dev`, `build`, and `test` pipelines.

### ⚡ Performance Optimizations
- **Redis Caching:** Implemented a "Cache-Aside" strategy for public event routes, reducing response times to <2ms.
- **Payload Pruning:** Optimized the Events API to strip non-essential data from public feeds, reducing response sizes by ~60%.
- **Database Indexing:** Added B-tree and compound indexes to MongoDB schemas for optimized search and filter queries.
- **Cold-Start Optimization:** Modularized the backend entry point to reduce bundle size and serverless cold-start latency.

### 🛠️ Stability & Monitoring
- **Deduplicated System Logging:** Implemented a new `logSystemError` utility that hashes and aggregates identical errors to prevent log spam.
- **Enhanced Health Dashboard:** Updated the Admin Panel UI to display error "Occurrences" and "Last Seen" timestamps.
- **Backend Modularization:** Refactored the monolithic `api/admin.js` into functional sub-modules for better maintainability.

### 🔧 Fixes & Refinements
- **Environment Management:** Fixed `.env` loading issues for monorepo workspaces using centralized absolute pathing.
- **Unified Build Pipeline:** Integrated static asset deployment for the `web/` folder into the main Turbo build process.
